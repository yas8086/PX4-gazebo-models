### 📐 几何参数计算方法

本文件中的几何参数通过 `read_stl_metadata.py` 脚本计算得出：

#### 1. 边界框中心（Bounding Box Center）
```
计算公式：
  center_x = (x_min + x_max) / 2
  center_y = (y_min + y_max) / 2
  center_z = (z_min + z_max) / 2

说明：
  - 分别找到X、Y、Z三个坐标的最小值和最大值
  - 每个轴的中心点 = (最小值 + 最大值) / 2
  - 也称为"包围盒中心"或"边界框几何中心"
```

#### 2. 质心（Centroid / Vertex Average）
```
计算公式：
  centroid_x = sum(所有顶点X坐标) / 顶点总数
  centroid_y = sum(所有顶点Y坐标) / 顶点总数
  centroid_z = sum(所有顶点Z坐标) / 顶点总数

说明：
  - 遍历STL文件中所有三角形的3个顶点
  - 计算所有顶点坐标的算术平均值
  - 也称为"顶点平均中心"或"质量中心"
  - STL文件本身不包含密度信息，所以这里假设所有顶点权重相等

示例（以灵云01主体为例）：
  - 三角形数量: 67,372
  - 顶点总数: 67,372 × 3 = 202,116 个顶点
  - 质心 = 202,116个顶点的坐标平均值
```

#### 3. 尺寸计算（Size）
```
计算公式：
  size_x = x_max - x_min
  size_y = y_max - y_min
  size_z = z_max - z_min

说明：
  - 边界框在三个轴向的宽度
  - 等于该轴最大值减去最小值
```

### ⚠️ 原点设置说明

- **原点错误**：结构工程师在SolidWorks中绘制时，未将原点设置在飞艇主体的中心点
- **统一错误原点**：所有9个STL文件的原点都是同一个错误原点（可能是坐标系原点(0,0,0)）
- **坐标仍有效**：尽管原点设置错误，但由于使用的是**绝对坐标**，各组件之间的相对位置关系是正确的
- **安装位置可确定**：基于绝对坐标，可以准确确定每个电机在飞艇上的安装位置
- **核对位置可确定**：通过对比各STL文件的边界框中心坐标，可以验证组件间的空间关系是否正确
